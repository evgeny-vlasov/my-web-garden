The robotics loop

Sense → Decide → Act

SenseRead a button, distance, light, time, or simulated world.
DecideUse conditions, state, and goals to choose what happens next.
ActMove, light an LED, sound a buzzer, display a message, or adjust.

Then the machine senses again. Feedback turns a list of commands into behaviour that can respond to the world.

Start with the system

Robotics is more than owning a robot.

A simulation can expose movement logic. An LED can make output visible. A button can become a sensor. A reaction timer can introduce measurement, fairness, and state.

Physical hardware adds friction that matters: wires come loose, motors drift, sensors produce noisy readings, and the real floor does not behave like the perfect diagram. Students learn to separate code problems from system problems and use each failure as information.

Theory is the skeleton. A physical build makes the skeleton move.
