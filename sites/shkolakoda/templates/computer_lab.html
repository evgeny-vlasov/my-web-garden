School of Code / Computer Lab

More room for a project to become the student's own.

Classes teach ideas in a planned sequence. The Computer Lab is guided project time for finishing a difficult section, changing a rule, repairing a bug, or building a more ambitious version.

Two kinds of work

Class first. Lab when the project needs more room.

CLASSES = PLANNED LEARNING PATH

Learn the idea

A class has a topic, a clear example, a guided build, and checkpoints. Lessons connect so the same ideas return in larger systems.

COMPUTER LAB = GUIDED PROJECT TIME

Follow the problem

The student chooses a useful next move and works with an instructor nearby: add a feature, investigate a failure, rebuild a weak section, or prepare a demonstration.

Choosing the work

Stay with a good problem.

A half-working project may contain more useful questions than a fresh assignment.

  • Finish a class project
  • Rebuild it another way
  • Add one feature
  • Test a strange idea
  • Repair a bug or edge case
  • Follow a challenge card
  • Prepare a demonstration
  • Help another student after trying independently

Instructor role

Help without taking over the keyboard.

The instructor can narrow the problem, ask for a prediction, point to evidence, suggest a test, or offer a challenge card.

The student makes the decision, changes the project, and explains the result.

Working rulesStudents arrive with a project or choose one connected to class. Browsing, videos, and games serve the build; they are not the activity by themselves.
