This page explains where Roblox belongs in the School of Code direction. It is not a current schedule, registration announcement, or claim that the preview projects are ready for class.

Why it belongs

A game world can become a reason to learn text-based code.

Students who understand events, conditions, variables, and game state in Scratch can meet those ideas again in Lua. The syntax changes; the underlying questions remain.

Roblox adds 3D coordinates, object hierarchies, properties, reusable functions, simple NPC behaviour, and the responsibility of making rules understandable to other players.

Class and Lab direction

Learn the rule together. Build a different world around it.

A future class would introduce one Lua structure and use it in a guided system. Lab work could then change the level, combine challenge cards, test fairness, or repair a state bug without becoming free-play time.

Account, privacy, device, and publishing arrangements would be decided before any future group opens.

Familiar games can lead toward unfamiliar ideas.

Roblox has educational value when students build original rules, understand scripts, inspect assets, and test what other players experience. Playing alone is not the program.
