Class format

A serious lesson can wear a ridiculous costume.

The funny premise earns attention. The class makes the system visible underneath it.

  1. 01
    Meet the ideaName one concept with a small example.
  2. 02
    Predict and testSay what the code should do, then run it.
  3. 03
    Build togetherUse the idea in a guided project.
  4. 04
    Change the systemAdd a rule, repair a bug, or rebuild a weak part.
  5. 05
    DemonstrateShow what changed and explain the evidence.
