PSYLING.COM - MAILGUN DNS RECORDS FOR CLOUDFLARE

Eugene, add these DNS records to Cloudflare for the psyling.com domain.

After adding records:

2. Verify in Mailgun dashboard (domain should show "Active")
3. Run test script: cd /var/www/webgarden/sites/psyling && python3 test_email_smtp.py

-----------------------------------------------------------------------------

RECORD 1: SPF (Sender Policy Framework)
Type:     TXT
Name:     @ (or psyling.com)
Value:    v=spf1 include:mailgun.org ~all
TTL:      Auto (or 3600)
Proxy:    DNS only (grey cloud ☁️) - DO NOT PROXY

Purpose:  Authorizes Mailgun to send email from psyling.com domain

-----------------------------------------------------------------------------

RECORD 2: DKIM (DomainKeys Identified Mail)
Type:     TXT
Name:     smtp._domainkey
Value:    <GET FROM MAILGUN DASHBOARD - see instructions below>
TTL:      Auto (or 3600)
Proxy:    DNS only (grey cloud ☁️) - DO NOT PROXY

Purpose:  Email signature verification (prevents spoofing and improves deliverability)

⚠️  TO GET DKIM VALUE:
1. Login to Mailgun: https://app.mailgun.com
2. Go to: Sending → Domains → psyling.com
3. Click "DNS Records" tab
4. Find the TXT record for "smtp._domainkey.psyling.com"
5. Copy the entire value (starts with "k=rsa; p=...")
6. Paste into Cloudflare DNS

Example DKIM value format:
k=rsa; p=MIGfMA0GCSqGSIb3DQEBAQUAA4GNADCBiQKBgQDd... (very long string)

-----------------------------------------------------------------------------

TTL:      Auto (or 3600)

Purpose:  Click and open tracking for email analytics

CLOUDFLARE SPECIFIC INSTRUCTIONS
-----------------------------------------------------------------------------

1. Login to Cloudflare: https://dash.cloudflare.com
2. Select domain: psyling.com
3. Go to: DNS → Records
4. Click "Add record" for each DNS record above

IMPORTANT SETTINGS:
  ✓ Proxy Status: DNS only (grey cloud ☁️) for ALL email records
  ✗ DO NOT use Proxied (orange cloud 🟠) for email records
  ✗ Proxied records will BREAK email authentication

Why DNS only?
  - Email authentication requires direct DNS access
  - Cloudflare proxy interferes with SPF/DKIM verification
  - "DNS only" allows proper email delivery

TROUBLESHOOTING
-----------------------------------------------------------------------------

Problem: DNS records not showing after 1 hour
Solution:
  1. Verify records added correctly in Cloudflare
  2. Check proxy status is "DNS only" (grey cloud)
  3. Try clearing DNS cache:
     - Cloudflare: DNS → Records → Purge Cache
     - Local: Clear browser DNS cache
  4. Wait longer (up to 24 hours for full propagation)


Problem: Mailgun shows "Unverified" status
Solution:
  1. Click "Verify DNS Settings" button in Mailgun dashboard
  2. Check exact value matches what Mailgun expects
  3. Ensure no extra spaces or quotes in DNS value
  4. Wait 10-60 minutes and check again


Problem: SPF record conflicts (if you have existing SPF)
Solution:
  - You can only have ONE SPF record per domain
  - If existing SPF exists, modify it to include Mailgun:
    Before: v=spf1 include:existing.com ~all
    After:  v=spf1 include:existing.com include:mailgun.org ~all
  - Do NOT create multiple SPF records


Problem: "Too many DNS lookups" error
Solution:
  - SPF has a 10 DNS lookup limit
  - Count includes in your SPF record (including nested lookups)
  - If over limit, consider using Mailgun's relay-only setup
  - Or use IP address instead: v=spf1 ip4:192.168.1.1 include:mailgun.org ~all
